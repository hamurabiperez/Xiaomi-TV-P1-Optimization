# Security

ADB debugging grants powerful control of a device. Use it **only on a trusted local network** and disable it when finished. Never expose TCP port 5555 to the public Internet.

Avoid publishing raw diagnostics, device identifiers, account logs, pairing information or screenshots without manual review. For potential credential exposure, contact the project maintainer through GitHub rather than attaching private values to a public issue.

No automatic package-disable, factory-reset, or firmware-modification tool is included.
