# Contributing

Contributions are welcome if they are **verifiable and reversible**.

1. Describe exact TV model, Android version, firmware and Projectivy version. Do **not** include serial, MAC, private IP or account identifiers.
2. State what was observed vs. inferred. Include before/after measurements only when the sampling conditions are comparable.
3. Explain the rollback path and any dependencies before recommending `pm disable-user`.
4. Avoid untested package blacklist lists, unverified performance claims and unattended destructive scripts.
5. Remove personally identifying information from screenshots and logs before attaching them.

This repo is an independent case study and not Xiaomi/Google/Projectivy support.
